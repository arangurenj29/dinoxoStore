# Ensayos vectoriales históricos — no operativos

Estos archivos se conservan exclusivamente para documentar la evolución del proyecto. Fueron descartados porque simplifican la textura, el metal, la iluminación y la composición del logo raster aprobado.

Reglas:

- no importar estos archivos desde web, redes, PDF, herramientas de build ni piezas comerciales;
- no publicarlos como variantes, símbolos, favicons o maestros;
- no usarlos para reconstruir o regenerar el logo;
- usar siempre `brand/assets/logo/dinoxostore-logo-primary.png` como fuente de verdad;
- reservar SVG operativo exclusivamente para `brand/assets/icons/`.
